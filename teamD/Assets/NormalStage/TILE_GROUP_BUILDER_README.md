# タイルグループ作成ツール

Unityメニュー **Tools > Normal Stage > Tile Group Builder** で開きます。

## 作成する

1. 左のパレットで通常床・方向転換・ギミックのセルを選びます。
2. 中央のマス目を左ドラッグして形を描きます。同じマスを塗るとセルの種類を置き換えます。
3. 必要ならShift＋クリックで配置の原点を変更します。黄色の「◎」がPrefabルートの位置です。
4. 右側でPrefab名、固定／移動可能、1マスのサイズを設定します。通常のステージはサイズ1です。
5. **Prefabを新規保存**を押します。初期保存先は`Assets/NormalStage/Prefab/TileGroup`です。
6. 保存したPrefabをステージのTileGridの子として配置します。セルが配置可能範囲内に入り、他のグループと重ならないようにしてください。

| 操作 | 内容 |
| --- | --- |
| 左ドラッグ | 選択したセルを描く。「消す」モードでは削除 |
| 右ドラッグ | セルを削除 |
| Shift＋左クリック | Prefabの原点を指定 |
| Alt＋左クリック | 置いたセルをスポイトで選択 |
| 元に戻す／やり直す | ドラッグ1回を単位にUndo／Redo |
| 表示範囲 | 5×5〜25×25マス。縮めても範囲外のセルは消えない |
| 小さく表示 | マスを縮めて広い形を見渡す |

上が+Z、右が+Xです。矢印は方向ごとのセルを選択します。離れたセルも1つのグループとして作成でき、その場合は注意が表示されます。

## 保存・再編集

保存すると同名の **`.prefab`と`.asset`** ができます。`.asset`はこのツール専用のレイアウトです。ダブルクリック、またはツールの「レイアウトを読み込む」で再編集できます。

- 保存は毎回新規作成です。同名がある場合は`_1`、`_2`のように連番を付けます。
- レイアウトの再編集はコピーに対して行うので、保存済みPrefabや元のセルPrefabは変更されません。
- 形とセルの種類はレイアウト側で編集します。ワープの移動量などセル固有の値は、保存したPrefabをPrefab Modeで開き、子のセルのInspectorで設定します。
- **Prefab Modeで行った変更はレイアウトには逆反映されません。** レイアウトから作り直すときは必要な個別設定を再適用してください。
- 手札のサムネイル用`PreviewOffset`は形の中央に合わせて自動設定します。手札一覧への追加は従来どおり`TileGroupTableData`側で行います。
- ウィンドウ内の編集中データはスクリプト再コンパイルをまたいで保持されます。ウィンドウを閉じる前に保存してください。

## 対応セル

`Assets/Tile/Prefab/TileCell`、`Assets/Gimmick/Prefab/TileCell`、`Assets/NormalStage`から、ルートに有効なTileCellを1つ持ち、TileGroupを含まないPrefabを自動収集します。別フォルダーのセルも「追加セル」に指定できます。

セルを**Nested Prefab**として保存するため、マテリアル・Collider・ギミックコンポーネント・進入イベントの接続を引き継ぎます。新しいランタイムスクリプトは不要です。1マスのサイズを変える場合はセルのXZ間隔とXZスケールを変更し、高さは維持します。

- 崩れる床（BreakableTile）は既存実装がグループ全体を破壊するため、1セルだけのグループで使用できます。
- 減速床はシーン側のSlowTileSpeedControllerの設定が必要です。
- ON/OFF床・スイッチなど、グループ単位の専用Prefabはパレット対象外です。既存の専用Prefabをそのままステージへ配置してください。
- ワープは既存セルの仕様・移動量を引き継ぎます。このツールはワープの仕組み自体を変更しません。

## 実装・検証

実装は`Assets/NormalStage/Editor`内にあります。既存の`Edtior`フォルダーはUnityのEditor専用フォルダーとして認識されないため、新たに正しい名前の`Editor`を使用しています。

**Tools > Normal Stage > Verify Tile Group Builder**で、実アセットの保存・読み直し、Nested Prefabとイベント参照、TileGridへの登録、同名保存、入力検証を実行できます。一時アセットは同フォルダー内に作成し、終了時に削除します。開いているシーンは保存・切替しません。
